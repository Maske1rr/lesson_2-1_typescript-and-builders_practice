# Короткая справка

## Ввод и типы

```ts
const raw = new FormData(form).get('seats')
if (typeof raw !== 'string' || raw.trim() === '') return null
const seats = Number(raw)
if (!Number.isInteger(seats) || seats < 1 || seats > 5) return null
return seats
```

`typeof` сужает тип, `Number` преобразует значение, `Number.isInteger` проверяет целое число. `as` не выполняет эти действия. `strict` проверяет договорённости в коде; данные пользователя нужно проверять при запуске.

```ts
type BookingStatus = 'new' | 'confirmed'
// В interface поле записывается как name: string
// Массив: Booking[] или Array<Booking>
```

## Импорты

```ts
// Из src/lib/count-seats.ts:
import type { Booking } from '../models/booking'
// Из src/main.ts:
import { countSeats } from './lib/count-seats'
import workshopUrl from './assets/workshop.svg'
```

`export` ставится перед объявлением типа или функции. `./` означает текущую папку, `../` поднимает на уровень выше. Импорт картинки возвращает URL, а не DOM-элемент. В `tsconfig.json` уже подключён `vite/client` для типов ресурсов.

## Команды

| Команда | Результат |
| --- | --- |
| `npm ci` | Установка версий из lockfile |
| `npm run dev` | Сервер разработки Vite |
| `npm run typecheck` | Проверка типов без генерации JS |
| `npm run build` | После Б1: проверка типов и сборка в `dist` |
| `npm run preview` | Локальный просмотр уже собранного `dist` |

Остановить сервер: Ctrl+C. Для проверки типов откройте второй терминал в той же папке. `preview` не предназначен для production-хостинга. Успешный `build` не проверяет правильность расчёта или поведение формы.

Все обязательные приёмы разобраны в лекции. Для углубления: [сужение типов](https://www.typescriptlang.org/docs/handbook/2/narrowing.html), [generics](https://www.typescriptlang.org/docs/handbook/2/generics.html), [TypeScript в Vite](https://vite.dev/guide/features.html#typescript), [импорт ресурсов](https://vite.dev/guide/assets.html). Поисковые запросы: «TypeScript narrowing typeof», «TypeScript Array generic», «Vite static asset import».
